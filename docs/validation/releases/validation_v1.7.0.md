# v1.7.0 VMC 原始测量生成验证

2026-10-10，Linux / Python 3.12 / NumPy 2.5.3 / PyQt6 6.11，Qt offscreen。

## 数值与文件

`python -m unittest discover -s tests -v`：70 项测试通过（原 62 项 + 新增 8 项，部分包含多组子用例）。

新增检查：

- 正向生成器独立求解两个端口激励的内部波量；使用手写 SOL / 普通 Thru / CalTHRU / MUT 传输闭式表达式核对，包含 RF / IF 两个物理频段的真实相位和单程跟踪。
- 上下变频 × RF / IF / dual 横轴 × 独立非对称端口误差盒：校准回收 S11 / S22 / VC21 和全部 21 项误差真值；绝对容差 3e-14。
- 非理想共享 SOL、非互易 / 非零反射的普通 Thru、导入 IF 横轴的校准混频器；两种定义插值均能回收 MUT。输出表征文件标准化为 RF 横轴。
- 线性幅度 / 解缠绕相位插值跨 ±180°、禁止外推；不一致阻抗拒绝；不合法频段 / 横轴 / 点数 / 参数和病态正向方程拒绝。
- 非整步长 LO、RF / IF 重叠时显式 RF 或 IF 横轴；双频段复制禁止重叠。
- 固定 PCG64 种子重复性；4 次平均使相同噪声样本缩小到 1/2；原始噪声不污染真值；双频段保留同一噪声矩阵；断开的 SOL 交叉传输保持零。
- 原子发布唯一运行目录，不覆盖旧结果；模拟写入失败后无暂存目录残留；解析输出、校验源文件副本 / 输出 SHA256，NPZ 无 pickle。

另与此前独立 `VMC_DummyDUT_RF10-20_IF30-40_baseline.zip` 的本地生成源文件比较：默认物理频率轴仍为 10～40 GHz / 601 点。六个 raw 文件各参数的最大复数差分别为 OPEN 4.003e-16、SHORT 3.724e-16、LOAD 0、THRU 0、CalTHRU 1.310e-16、MUT 1.186e-16；差异属于浮点计算舍入。
