# v1.8.0 默认查看页与流程导航验证

- `python -m unittest discover -s tests -v`：70 项数值 / 文件回归通过。
- `tests/gui_simulation_smoke.py`：两轮 SOL 后台生成、真值传递、表征联动、噪声、设置与失效。
- `tests/gui_vmc_calibration_smoke.py`：原有 VMC 求解 / MUT / 导出 / 保存 / 重载与主界面联动。
- `tests/gui_viewer_display_smoke.py`：幅度 / 相位 / 解缠绕右键菜单、分段与零幅度、独立 Y 轴范围与非法范围拒绝。
- `tests/gui_vmc_simulation_smoke.py`：原有独立生成窗口、校准传递、物理频率轴、实际标准输入、错误恢复。
- `tests/gui_workbench_smoke.py`：新增主工作区集成检查，覆盖默认启动无需项目、多文件勾选叠加、颜色稳定、每文件频率轴恢复、仅查看选中文件、移除 / 清空、差异计算与数据更新后重建、共享校准状态、生成子页返回、嵌入式后台生成 → 求解 → 校准 MUT → 默认查看页、工作中拒绝关闭、排队导入在后台结束后继续、底部日志汇总。
- 实际主窗口在 1420×900 与 1000×700 渲染并检查；校准导航全部页面保持 1000 像素窗口宽度。较小窗口下侧栏 / 输入页通过滚动访问全部控件。
- 默认曲线按 S11 / S21（VC21）上排、S12 / S22 下排布置；内部 axes 数组维持 PARAMS 顺序。固定数据集颜色和线型，取消勾选不删除数据；表格与导出仍属于当前选中文件。
- 在导入本地 CJK 字体后检查真实 Qt 截图，修复页面切换时待删除按钮浮于工作区的问题；计算误差项操作置于页头，不依赖滚动配置栏才能访问。
- `git diff --check` 通过。

## 范围

叠加只按各文件自行选择的实际轴绘制，未增加插值、频点重排、自动 RF / IF 换算或时延拟合；差异计算继续使用唯一频点匹配。验证报告页复用既有误差统计和 CSV，不自动给出容差通过结论。当前仍为双端口查看与 VMC 单向 MUT 模型；SOLT / TRL / 多端口与通用项目文件保存未因界面或名称升级而实现。

本记录是容器中的 Qt / 数值验证，不代表已完成 Windows 桌面、Keysight / R&S 仿真器或仪器现场验证。
