# v1.5.2 验证记录

日期：2026-10-09。Linux / Python 3.12；Qt offscreen；未在 Windows / PNA 现场验证。

## 修改内容及明确行为

- 三次样条在完整标准频率定义上分别对线性幅度 `abs(Gamma)` 和弧度相位 `unwrap(angle(Gamma))` 求值，均采用 not-a-knot，禁止外推。结果为 `mag_interp*exp(j*phase_interp)`；不是 dB 幅度样条。
- 历史键 `cubic_ri` 保留，v1.5.2 起实际代表幅相样条。两处 GUI 选项及提示、JSON / S2P 注释记录 `cubic_magnitude_unwrapped_phase`，并记录版本。
- 精确节点优先保留原复数值；恒零 LOAD 保持零，不进行相位解缠绕。
- 非恒零标准含零幅度且需要任一种插值时拒绝，不给该点虚构相位；全部请求命中精确节点则返回原值。
- 样条产生负幅度时明确报错，不取绝对值或钳位；可以改用幅相线性或提供更合适的标准定义。

## 待验证与限制

- 上述差异只描述该回归数据，不是仪器测量准确度，也不能确认 Keysight 内部采用相同幅相样条算法。
- v1.5.0 / v1.5.1 的 cubic_ri 是 RI 样条；复现实验必须区分版本和实际插值坐标，历史报告保留不改写。
- 相邻采样不足时 np.unwrap 无法保证真实相位分支；本次不做自动拟合或稀疏相位恢复。
- 上变频 Keysight 对照、完整物理标准套及 Windows / PNA 现场尚待验证。
