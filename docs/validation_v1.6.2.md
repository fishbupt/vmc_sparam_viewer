# v1.6.2 VMC 校准窗口布局检查

日期：2026-10-10。此次修改为 GUI 布局与文件分组；校准算法、数据格式与已有输入键保持不变。

运行 `python tests/gui_vmc_calibration_smoke.py`（已安装项目依赖的虚拟环境）通过：

- 两个页签仍为“计算 VMC 校准误差项”“校准 MUT”，没有独立比较页。
- RF / LO / 自动派生 IF、求值 / 横轴及 MUT 横轴控件位于左侧。
- THRU 定义与 OPEN / SHORT / LOAD 定义在同一组。
- THRU / CalTHRU 原始数据与 OPEN / SHORT / LOAD 原始测量在同一组。
- 已表征校准混频器的输入独立成组。
- IF 起止显示与 RF / LO / 方向配置一致；共用 / 独立 SOL 模式切换正常。
- 1320×940 与 1000×700 窗口下保持左右布局；高级 SOL 和较小窗口通过各自滚动区访问全部输入。
- 后台求解、校准 MUT、主界面联动、校准包保存 / 重载、结果导出、设置记忆和分级失效仍通过。
- THRU 未启用 S2P 定义时，路径与浏览按钮一并禁用。

`git diff --check` 通过。截图输出默认位于临时目录，可用 VMC_GUI_SCREENSHOT_DIR 指定检查目录；Windows 原生字体和现场软件运行仍需用户确认。

数值算法回归范围与62项结果见 validation_v1.6.0.md；本次只同步应用版本字符串，未修改公式或重新解释既有 Keysight 对照结论。
