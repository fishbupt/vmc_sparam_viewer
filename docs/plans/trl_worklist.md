# TRL 校准验证工作清单

更新日期：2026-10-13。开发分支：`trl`。
基础分支：`Enhanced`；已同步 v1.9.0 结构。初始规划基准提交：`0bd7f3abc2a93fb32ee2c6af254abc801326e4a3`（GUI / 包版本 1.8.3）。

目标：完成“标准定义 → 原始测量生成 / 导入 → TRL 求解 → DUT 双向校准 → 真值 / 独立实现 / Keysight 对照 → 验证报告”的闭环。

当前已完成分支、开发清单和结构同步；TRL 算法、生成器及 GUI 尚未实现，菜单继续显示待实现。文档规划不改变软件版本或现有 VMC 算法报告版本。

## 1. 首轮范围及执行顺序

优先实现同频双端口、单条 LINE 的基础 TRL，校准 DUT 的 S11、S21、S12、S22。先完成显式零开关项 / 零隔离的受限仿真基线，再实现非零开关项及目标仪器数据适配；不得把受限基线称为完整仪器校准。

| 里程碑 | 工作 | 完成条件 | 依赖 |
| --- | --- | --- | --- |
| M0 | 确定标准、误差模型、采集格式和数学约定 | 输入及求解规范、目标 Keysight 状态清楚 | 无 |
| M1 | 独立原始测量生成器 | 可重复生成标准 raw、DUT raw、真值和追溯报告 | M0 |
| M2 | 基础 TRL 求解与 DUT 校准 | 四参数无噪声恢复、分支 / 参考面 / 阻抗检查通过 | M0、M1 |
| M3 | 独立参考、失效用例和噪声验证 | 固定版本独立实现交叉验证及回归报告 | M2 |
| M4 | TRL GUI 接入 | 生成 / 导入 → 求解 → 校准 DUT → 比较完整联动 | M2，验收依赖 M3 |
| M5 | Keysight 仿真及实机对照 | 相同输入、标准和参考面下形成可追溯样本 | M3、M4、实际数据 |
| M6 | 扩展及正式发布 | 按已验证覆盖范围更新说明和支持状态 | M5 |

不将通用 N 端口改造、全部 SOLT 或其他校准算法设为基础双端口 TRL 的前置条件。按需抽取共用接口，保留现有 VMC、数据查看及比较行为。

首轮暂不实现：Multiline TRL / NIST mTRL、TRM / LRM / LRL、多端口 TRL、Delta Match、波导色散、AFR 和混合模。为这些扩展保留接口，不提前宣称支持。

## 2. M0：输入规范与模型约定

- [ ] 建立 `docs/algorithms/trl/`：固定端口方向、S / 链矩阵定义、正反向激励、复数相位与时延符号、模型自由度和求解推导。
- [ ] 定义两端误差盒及开关项模型；区分八项模型表示、厂商十二项表示和两者适用的转换条件，不将现有 VMC 误差项直接当成 TRL 误差项。
- [ ] 明确 THRU / LINE 具有相同介质、特征阻抗及传播常数的基础假设；不要求算法拿到完整 LINE 真值或 REFLECT 精确复数真值才能完成自校准。
- [ ] 定义 THRU 长度 / 延迟及参考面设置；先支持 Flush THRU，再验证非零长度 THRU。将 Unknown Thru 与 TRL 已定义 THRU 区分。
- [ ] 定义两端 REFLECT 的同一响应假设和相位初值（例如近似 OPEN / SHORT）；将真实反射响应仅作为生成器 / 验证的真值，不泄漏给求解器。
- [ ] 明确 LINE 与 THRU 的相对电长度要求及退化频点诊断。以 Keysight 的 20°～160°建议作为选线提示；算法另外判断特征值分离、条件数和数值退化，不把建议范围当作唯一失效规则。
- [ ] 明确校准原生参考阻抗由传输线决定；区分 Touchstone 文件中的 R 值、LINE 实际特征阻抗和用户目标阻抗。先保持原生阻抗；只有有依据的阻抗输入才能启用显式重归一化。
- [ ] 定义开关项方向和接收机比值，区分“原始已终接比值”“已去开关项数据”“显式零开关项仿真数据”；避免重复修正。缺失数据拒绝完整模式，受限模式必须显式选择和记录。
- [ ] 定义隔离数据可用性；首轮显式零隔离，非零泄漏须在模型和采集中获得支持后验证，不默认为已修正。
- [ ] 定义频率网格一致性、唯一容差、有效频段、参考阻抗、端口顺序及分段规则。原始测量不插值、不自动丢点；不得让现有 VMC 插值配置隐式作用于 TRL 原始采集。
- [ ] 确认 Keysight 仿真软件 / PNA-X 型号、版本、固件、实际 TRL 类型、接收机架构及必要中间数据，形成目标覆盖矩阵。

## 3. M0 / M1：数据及文件接口

以下为计划文件名，需在 M0 固化为输入清单和解析规则。

| 数据 | 计划文件 | 使用说明 |
| --- | --- | --- |
| 标准描述 | `trl_standards.json` | THRU 参考面、LINE 相对长度 / 延迟及有效频段、REFLECT 相位初值、阻抗来源 |
| THRU 原始测量 | `thru_raw.s2p` | 正反向完整四参数 |
| LINE 原始测量 | `line_raw.s2p` | 正反向完整四参数 |
| REFLECT 原始测量 | `reflect_p1_raw.s1p`、`reflect_p2_raw.s1p` | 两端分别记录反射测量及连接状态 |
| 双端反射可选输入 | `reflect_raw.s2p` | 明确连接和对角项提取规则；交叉项不作为 REFLECT 定义 |
| 开关项 | `switch_forward.s1p`、`switch_reverse.s1p` | 自定义比值及方向，不按普通单端口器件 S11 含义解释 |
| 隔离可选输入 | `isolation_raw.s2p` | 与两种激励状态一致，仅在适用模型下使用 |
| DUT 原始测量 | `dut_raw.s2p` | 完整四参数，不限制为互易 DUT |
| DUT 真值 | `dut_truth.s2p` | 仅供验证；禁止进入校准求解 |
| 标准真值 | `thru_truth.s2p`、`line_truth.s2p`、`reflect_p1_truth.s1p`、`reflect_p2_truth.s1p` | 仅供生成追溯 / 验证；与求解使用的有限已知定义区分 |
| 厂商校准输出 | `dut_keysight_calibrated.s2p` | 记录校准类型、参考面、参考阻抗与实际仪器状态 |
| 运行记录 | `manifest.json` | 数据层级、输入 / 输出哈希、参数、随机种子、算法 / 文件版本 |

- [ ] 支持可配置两端不同误差盒，覆盖方向性、匹配和跟踪；保留复数真值、模型参数与归一化说明。

- [ ] 首个基线：10～20 GHz、201 点、Flush THRU、LINE 相对 THRU 延迟 12.5 ps、近似 SHORT 的 REFLECT、不同端口误差盒、显式零开关项 / 零隔离、无噪声。该选线在基线内相对相位为 45°～90°，不沿用 VMC 的 LO / IF 配置。
- [ ] 基线之外加入非零正反向开关项；分别输出已终接原始数据与适用的去开关项参考，独立验证处理方向。

- [ ] 每次新建独立运行目录，输出标准定义、全部 raw / clean / truth、预期参数及追溯记录；失败清理暂存文件，不覆盖之前结果。

- [ ] 处理非零长度 THRU 的参考面，验证两端移动量和符号；阻抗重归一化与参考面移动作为独立、可追溯步骤。
- [ ] 实现非互易 DUT 四参数修正，保持频率及原始行号；对不可修正频点输出有效性标志和原因，不悄悄删点或填零。
- [ ] 输出特征值分离、条件数 / 残差、有效点、分支和标准一致性诊断；明确矩阵奇异、近零传输、非有限值和模型不满足的错误。
- [ ] 校验包保存 / 重载结果相等，错误算法包、损坏数组、频率 / 端口 / 阻抗不兼容时拒绝使用。
- [ ] 有采集和规范证据后才转换厂商十二项误差项；不能映射的项单独说明，不套用 VMC 单向 MUT 公式。

## 6. M3：独立验证与回归矩阵

| 用例 | 要验证的行为 | 预期证据 |
| --- | --- | --- |
| 理想标准、无噪声、不同误差盒 | 四参数校准恢复 | 每参数复数最大差 / RMS 及曲线 |
| 独立解析 / 波量小样本 | 正向方程与求解方向正确 | 解析结果或独立计算对照 |
| 固定版本 scikit-rf 基础 TRL | 独立算法交叉检查 | 同输入、同模型和参考面下的结果差 |
| 非零 THRU / 有损 LINE | 参考面及传播分支正确 | 复数恢复与传播 / 时延诊断 |
| 非理想同响应 REFLECT | 不依赖完整反射真值 | 只传初值的恢复结果 |
| 两端不同 REFLECT / 不同线阻抗 | 假设违背能被识别或揭示 | 失配、残差、偏差及适用性说明 |
| 非零开关项 | 两种激励状态和处理层级正确 | 有 / 无修正偏差及独立真值 |
| 相对相位接近 0° / 180° | 病态诊断而非伪装成功 | 有效点标志与诊断曲线 |
| 跨多圈、分段、稀疏采样 | 分支连续性及歧义处理 | 分支记录，无自动拟合 |
| 非互易、强反射、低传输 DUT | 四参数与数值边界 | 幅相 / 复数误差，零幅度相位排除 |
| 重复频点、频段不足、缺开关项 | 输入拒绝或明确受限模式 | 错误信息及结果失效 |
| 噪声 / 标准偏差扫描 | 稳定性与敏感性 | 随机种子、统计曲线及重复运行 |

- [ ] 将数值测试写入 `tests/trl/test_calibration.py`、`tests/trl/test_simulation.py`；用合成临时文件测试，不依赖被忽略的 `examples/` 个人数据。
- [ ] 将 scikit-rf 作为可选验证参考固定版本，明确其算法及默认选项；不能只用同一正向生成器与自研求解器互相吻合证明正确。
- [ ] 定义数值、噪声、厂商对比三类门限：无噪声门限结合条件数和浮点误差建立；厂商门限考虑原始数据精度。门限批准前只输出统计，不填任意数值宣称通过。
- [ ] 比较原生参考阻抗、参考面及去开关项层级一致的 DUT；误差盒系数只有规范自由度统一后才能直接逐项比较。
- [ ] 输出 S11 / S21 / S12 / S22 幅度、相位、解缠绕显示及复数差曲线；相位差按归一化差值统计，不利用解缠绕人为消除差异。
