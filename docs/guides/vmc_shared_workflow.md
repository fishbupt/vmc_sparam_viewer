# 共享 VMC 配置与五步流程

## 全局配置

在“VMC 全局配置”统一设置 RF 起止、固定 LO、变频关系、点数、参考阻抗、标准插值、频率容差和 VMC 原始测量横轴。IF 自动派生，支持 up / down / high_side。各步骤顶部显示同一份配置及实际原始文件横轴，不再分别恢复旧的扫频配置。

v1.11.1 起，RF/IF 频段相接或重叠时，全局会将不兼容的 dual 自动改为 RF，并显示调整原因，同时禁用当前频段组合的 dual 选项。频率配置继续保留；若之后改为不重叠频段，可重新选择 dual。

全局修改会使两轮 SOL 生成结果、表征结果、VMC 生成结果、校准包与 MUT 结果失效；磁盘文件和主界面已载入的数据快照保留。更换页面不会重新求解。工作期间禁用其它步骤的冲突操作。

## 五个步骤

1. **生成两轮 SOL**：使用全局配置，第一轮标准按 RF 求值，第二轮按 IF 求值。默认共用标准；勾选“端口 2 / 第二轮使用独立 OPEN、SHORT、LOAD”可加载另一套 S1P。内置合成 SOL 仍为共用测试套。
2. **表征校准混频器**：在步骤 1 点击载入表征，六个采集文件及三个 / 六个标准自动传入步骤 2。第二轮修正层级、开方符号是本步骤的设置。两轮测量的 RF 网格和阻抗须与全局配置一致。
3. **生成 VMC 原始测量 SNP**：表征完成后点击“将表征送入步骤 3”，程序将本次结果保存为唯一文件并加载到生成器，自动使用 RF 横轴，同时传入对应标准。也可手动导入其它已表征文件。
4. **校准求解**：生成器将标准、原始测量、已表征混频器和 MUT 路径送入步骤 4；端口 2 独立标准保持独立，计算当前误差项。
5. **校准 MUT**：使用当前校准包校准 MUT，原始和校准结果进入数据查看 / 比较。校准包可保存、重载；重载时将其配置恢复到全局。

独立标准的文件名为 Standard_P1_Open/Short/Load.s1p 和 Standard_P2_Open/Short/Load.s1p；共用标准仍保留旧文件名。数值接口接受按 P1 O/S/L、P2 O/S/L 排列的六路径，也兼容原来的三路径。

两轮表征阶段，P1 标准只需覆盖 RF、P2 标准只需覆盖 IF；VMC 的普通 SOL / THRU 包含两端口的 RF 与 IF 校准，因此用于该阶段的两套标准都要覆盖所需物理频率。需要时在步骤 3 导入完整定义，程序不外推。

## “已表征混频器 S11 超出范围”排查

表征文件中四个参数共用同一条文件横轴；S11 出错通常只表示它最先被求值。

- 本软件步骤 2 导出的表征 S2P 使用 RF 横轴，步骤 3 应选择“RF 横轴”。其中 S22 的数值虽对应物理 IF，文件行索引仍是 RF。
- 全局 RF 为 10～15 GHz 时，RF 轴表征文件必须覆盖 10～15 GHz。高边 LO 的 IF 10～5 GHz 不应拿去索引这份 RF 文件。
- 如果导入的是明确以 IF 排序的外部表征文件，选择 IF，并确保它覆盖全部 IF 频点；频率及各参数列必须同步排序。
- 文件频段不足时，缩小全局频段至已覆盖范围，或在正确的全局配置下重新表征。不要用外推或强制裁剪消除错误。

报错现在会给出文件路径、所选 RF/IF 横轴、文件频段、所需频段，并在另一横轴可覆盖时提示检查选择。不会自动改变外部文件的物理含义。


## RF 10～15 / LO 20 GHz 的原始 SNP 生成

高边 LO 的 IF 按 RF 点序为 10→5 GHz，两个物理频段在 10 GHz 相接。此时原始文件横轴应为 RF（也支持显式 IF 单轴），不能选 dual。表征文件若是步骤 2 的输出，横轴仍选 RF。

更新后即使旧设置保存了 dual，也会保留频率并统一改成 RF。步骤 3 的日志显示“VMC 实际生成配置”，可核对 RF 10～15 GHz、LO 20 GHz、high_side、点数、原始横轴 RF、表征文件横轴 RF。这两种横轴分别描述原始测量文件和导入的表征文件，不会因共用 RF 数值而混淆。
