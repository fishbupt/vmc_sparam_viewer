- 独立波量线性方程验证新增上变频正向模型，未用提取公式反推出测量输入。
- 上变频 LO 高于 RF 的合法配置、原始 / 已修正第二轮、复噪声可复现与平均缩放、IF 超出标准定义时不留部分输出、错误变频方向导致传输偏差均已测试。

## 模型假设和已确定行为

- 固定正 LO，仅支持 RF−LO 差频和 RF+LO 和频，均非反转；不支持 LO−RF 反转分支。
- 互易假设 C12=C21；整体 ± 符号和真实相位分支不是反射 SOL 独立识别的量。
- 两种插值均是实虚部分别求值，精确节点优先、禁止外推；样条 not-a-knot。无自动归一化、测量插值或参数拟合。
- 仿真噪声为相对于 S=1 的复数 RMS dB。Mixer.s2p 保持无噪声；生成的六个采集文件仅 S11 有效。
- SHORT 回归文件是 5～20 GHz 摘录，RF 10～20 GHz / LO 5 GHz 的上变频要求 IF 15～25 GHz，会拒绝；需提供完整标准件定义。
